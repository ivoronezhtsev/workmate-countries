### Workmate Countries - Приложение для отображения списка стран из сервиса https://restcountries.com/ ###
Использовал:  
Язык: Kotlin  
UI: Jetpack Compose ( без xml Single Activity)    
Network: Retrofit  
DB: Room
Архитектура: MVVM + Clean Architecture без оверинжиниринга с кучей слоев (поместил логику загрузки в class GetCountriesUseCase)  
Навигация: Navigation Compose

* HashSet - множестово (хранит уникальные значения) HashMap - ассоциативный массив или словарь хранит пары ключ->значение.  
Обе коллекции требуют переопределения методов hashCode, hashSet класса Object.  
 Алгоритм добавления элемента в HashMap:  
1. Проверка ключа на null, если true вызов метода putForNullKey
2. Генерация хэша на основе ключа (метод hash(key.hashCode())
3. Определение позиции в массиве куда будет помещен элемент с помощью метода indexFor(hash, tableLength)
4. Теперь зная индекс в массиве получаем цепочку элементов. Происходит перебор элементов в цепочке, если хэш и ключ совпадают то происходит перезапись
5. Если совпадение не выявлено будет добавлен новый элемент с помощью addEntry(hash, key, value, index)

* Корутины - легковесные потоки, в отличие от Thread не создается поток каждый раз, тысячи корутин могут работать на нескольких потоках.
